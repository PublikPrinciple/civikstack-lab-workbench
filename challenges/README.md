# Challenge catalog

## Start with care-fit

**[Daily afterschool care: potential fit, mismatch, or unknown →](care-fit/README.md)**

This is the first sample task environment for the November 10 Builder Lab. The Lab builds reproducible packages of harness, tools, behaviors, system prompt, context, permissions, and evaluation, seeking minimum sufficient intelligence. Hosts provide a [sample package](../task-environments/care-fit/package.json), common contract, synthetic cases, baseline, evaluator, and result template. Participants contribute one package change, source interpretation, or failure test. Read the [task-environment contract](../docs/TASK_ENVIRONMENT.md). See [Start here](../docs/START_HERE.md).
