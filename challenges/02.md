# 02: Understand a request

Status: available. Select this challenge through the repository Issues tab.

## Access context
Illustrative problem: families cannot determine which after-school programs meet their needs or have openings. This is not a verified research finding.

## Capability
Convert fictional plain-language requests into age and explicitly stated needs.

## Inputs and output
Use `fixtures/` and `docs/contracts.md`. Place your solution in `solutions/02/<approach>/`. Document input/output, dependencies, and reproduction steps. Tasks can be prototyped independently with fixture inputs.

## Acceptance evidence
Evaluate paraphrases, absent ages, and ambiguous needs; do not invent missing details.

## Boundaries
Synthetic data only. Cite evidence IDs. Preserve uncertainty. Any production model must be <=1B parameters. Return test results and limitations even if the experiment fails.
