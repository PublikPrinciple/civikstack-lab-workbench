# 06: Measure local performance

Status: available. Select this challenge through the repository Issues tab.

## Access context
Illustrative problem: families cannot determine which after-school programs meet their needs or have openings. This is not a verified research finding.

## Capability
Benchmark one approach on participant hardware without changing its behavior.

## Inputs and output
Use `fixtures/` and `docs/contracts.md`. Place your solution in `solutions/06/<approach>/`. Document input/output, dependencies, and reproduction steps. Tasks can be prototyped independently with fixture inputs.

## Acceptance evidence
Report runtime, repetitions, latency distribution, peak memory, correctness, and exact environment; identify any model and confirm <=1B parameters.

## Boundaries
Synthetic data only. Cite evidence IDs. Preserve uncertainty. Any production model must be <=1B parameters. Return test results and limitations even if the experiment fails.
