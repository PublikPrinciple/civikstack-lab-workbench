# README artwork

The orange/black ASCII playground banner reuses the user-supplied playground photograph and Canvas2D effect from the approved Builder Lab flyer (November 2, 2026, flyer version 8). Only the rendered banner and still are included here; unrelated flyer content and private source files are not included.

The exact user-supplied Community Intelligence League logo is centered in white, preserving its wordmark, proportions and transparent silhouette. The existing source logo is composited through a white canvas color filter; it is not redrawn or generated. Only transparent outer padding is excluded from placement. A subtle dark backdrop supports legibility.

The logo remains fixed above the scene while one low-contrast highlight moves slowly across the ASCII background. There are no flashes, cuts or randomized glyph changes. The GIF loops every four seconds. The README supplies a matching still image for reduced-motion preferences and an explicit static-artwork link. The meaningful instructions and diagram explanation remain readable text.

Rendering: existing flyer Canvas2D engine, orange-black palette, hexdump grid, 960×360 capture; encoded to a 720×270 GIF with 32 colors at 3 frames/second using installed FFmpeg. The PNG is the first encoded frame. This is a decorative image, not an interactive workspace or an inference interface. No JavaScript executes in the GitHub README.

Source artwork was supplied and its reuse authorized by the repository owner. This note records provenance; it does not select a repository-wide license.

`build-cycle.svg` is a newly authored static diagram with a title, description and readable-text equivalent in the README. It contains no scripts, external fonts or interactive controls.
