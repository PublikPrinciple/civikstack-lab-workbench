# First build session

6:00–6:20 arrival and setup; 6:20–6:30 short introductions; 6:30–7:30 build and connect; 7:30–7:45 voluntary demonstrations; 7:45–8:00 next steps.

Have participants test repository access and workspace startup before the event. Offer local Python or Dev Containers if the hosted environment is unavailable. Start with the six synthetic rehearsal cards; attach actual reviewed Access findings only when available. Ask each group to return an approach, evidence, limitations, and a next step.
